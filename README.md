## 🚀 Featured Work

### 👁️ AI Safety Monitoring
Built a real-time construction safety monitoring system combining
**YOLOv11 object detection with vision-language model reasoning**,
improving hazard-identification F1 from **34.5% → 50.6%** while adding
only ~2.5 ms of inference latency.

📄 Co-author of *Integration of Object Detection and Small VLMs for
Construction Safety Hazard Identification* (2026).

### 🤖 Remote Inspection Robot
Built a remote robotic inspection system using **ROS**, with a
**Unity/C# VR interface** for navigation and a high-performance
**FFmpeg-based video streaming pipeline**.

### 📱 TrackMe
Full-stack health tracking application built with **React Native,
TypeScript, FastAPI, SQLite, and Apple HealthKit**, featuring AI-powered
habit insights and nutrition integration.

### 🧬 Offspring.exe
Genetics simulator built with **React and TypeScript** that models
Mendelian inheritance and polygenic traits using a seeded Monte Carlo
simulation of **20,000 possible offspring**.
